# Remote Access

## SSH

SSH is used for remote terminal access.

Connect using:

ssh mattis@optiplex-5090

## Tailscale

Tailscale provides secure remote connectivity.

- Installed on server
- Installed on Ubuntu laptop
- Both devices connected to the same Tailnet
- MagicDNS used for hostname resolution

## Services

- SSH: Port 22
- Tailscale: VPN connectivity
